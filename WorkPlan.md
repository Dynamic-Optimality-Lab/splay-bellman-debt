## 1. The chain this plan implements (frozen, do not reorder)

```text
sealed v0.1 pair dynamics → fixed-b Bellman debt → exact debt-creation/repayment specimens
→ structural / recency kernel → candidate conserved resource Φ
→ universal KEEP/DELETE law → approximate monotonicity → dynamic optimality
```

**Positive endpoint:** one universal constant `b<∞` + explicit `Φ(z)≥0`, `Φ(z0)=0`, on declared Markov state `z` (primary `z=(A,B)`; gated augmented `z=(A,B,ρX,ρY)`), with KEEP `c(B,x)+Φ(z')−Φ(z) ≤ b·c(A,x)` and DELETE `Φ(z')−Φ(z) ≤ b·c(A,x)`, telescoping to `Splay(Y,T) ≤ b·Splay(X,T)` for all `Y⪯X`, then audited Levy–Tarjan → dynamic optimality.
**Negative endpoint:** explicit infinite family `(Tk,Xk,Yk)`, `Yk⪯Xk`, with `Splay(Yk)/Splay(Xk)→∞` (proves unbounded overhead; only then reverse bridge). Finite kernel/potential failure, single-b positive-regret cycle, or growing finite residuals are **not** disproof.
**Allowed terminal levels:** exact debt characterization only; kernel insufficiency; recency-necessity proof for a stated family; finite-surviving candidate; universal Pair Access proof; proved unbounded negative family; resource-limited/inconclusive. Finite evidence never promoted (§§25–26 enforced in WP-6).

**Frozen contract essentials (used by every WP, inherited read-only from parent, never redefined):** key universe `[n]`; BST universe `T_n`; canonical tree encoding; root depth 0; cost `c(T,x)=depth+1`; ordinary bottom-up Splay `S_x(T)`; sequence cost; position-based subsequence; pair state `(A,B)`; diagonal `Δ_n`; KEEP `K_x(A,B)=(S_xA,S_xB)` with `a=c(A,x),y=c(B,x)`; DELETE `D_x(A,B)=(S_xA,B)` with `a=c(A,x),y=0`; pair IDs; reachable domain `R_n`; path-to-sequence decoding; exact rational conventions. Fixed-`b`: `w_b(e)=y−b·a`, `ℓ_b(e)=b·a−y=−w_b(e)`, edge constraint `w_b(e)+Φ(t)−Φ(s)≤0 ⟺ Φ(t)−Φ(s)≤ℓ_b(e)`; `U_b(s)=inf_{Δ⇝s}Σℓ_b`, `V_b(s)=sup_{s⇝*}Σw_b` (empty continuation allowed, so `V≥0`); Bellman `V_b(s)=max(0,max_e[w_b(e)+V_b(t)])`, `U_b(t)=min_e[U_b(s)+ℓ_b(e)]` with diagonal source; corridor `V_b≤H≤U_b` for normalized nonnegative pair-state potentials only (does **not** constrain augmented potentials); edgewise `ΔV_b,ΔU_b,R^V_b=w_b+ΔV_b≤0,R^U_b≤0`; specimen classes `V_TIGHT,U_TIGHT,KEEP_EXCESS,CANONICAL_REPAYMENT,EXACT_V_REPAYMENT,CANONICAL_CREATION,MAX_CREATION_TIGHT,NO_DEBT_CHANGE` (finite classifications, not universal laws). Debt target: `D(z')−D(z)≤b·c_A` (DELETE), `c_B−b·c_A≤D(z)−D(z')` (KEEP). Integer-scaled `L_{p,q}(e)=p·a−q·y`; no float authoritative.

**SA-01 recency-`V` blindness (amends §8.4; theorem-level canary found by compliance audit):** recency updates `ρX,ρY` change neither the enabled actions, the `(A,B)→(A',B')` Splay transitions, nor costs `w_b(e)`. Hence `z1∼z2 ⟺ π(z1)=π(z2)=(A,B)` is itself a cost-preserving bisimulation, so `V_b^R(A,B,ρX,ρY)=V_b^R(A,B,ρ'X,ρ'Y)` necessarily for same `(A,B)`. Phase 08.4 therefore asserts `same (A,B) ⟹ same V_b^R` and treats **any nonzero spread as implementation failure** (`RECENCY_V_CANARY_FAIL`), never as debt-information evidence. Recency remains valuable as a history-dependent accounting representation: `U_b^R`, path-specific creation, candidate-`Φ` deltas, and structural simplicity are the interesting recency objects (see WP-4).

**Parent facts expected for import (must revalidate before becoming CERTIFIED_PARENT_FACT):** `|R_n|`: 4,19,196,1764,17424,184041 (n=2..7); `b_n*`: 1,1,3/2,8/5,8/5,23/14; b=2 geometry `maxU_2`: 4,10,22,38,44,58; `maxV_2`: 0,1,2,3,5,6; forced: 2,5,14,42,132,429 (=Catalan diagonal); WP-5 candidates H-0001..H-0006 all rejected (UH-4 upper/lower failures at n=3/4/5 as listed; UH-5 counterexamples preserved as supplementary). **Discovery anchor:** `b_anchor=2` (exact 2/1) — discovery anchor only, never theorem assumption; final `b_H∈ℚ>0` frozen per hypothesis, change creates new ID. **Secondary robustness panel (diagnostic, not tuning):** 5/2,3,4 on required n=2..5, stretch n=6..7; incompleteness → `ROBUSTNESS_PANEL_INCOMPLETE`, does not block anchor science.
